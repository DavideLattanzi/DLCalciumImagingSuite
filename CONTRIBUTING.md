# Contributing to DLCalciumImagingSuite (DL-CIS)

Thank you for your interest in contributing to **DLCalciumImagingSuite**!

## How to Contribute
1. **Report Bugs:** Open an issue on GitHub describing the bug with steps to reproduce it.
2. **Suggest Features:** Open an issue to discuss new analytical tools or GUI improvements.
3. **Pull Requests:** 
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/NewFeature`).
   - Commit your changes.
   - Push to the branch and open a Pull Request.

Please follow standard Python PEP 8 guidelines and include appropriate unit tests.
